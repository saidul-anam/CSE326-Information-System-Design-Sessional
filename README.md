# CSE326 Information System Design Sessional

This folder contains the full set of Information System Design Sessional materials for the Airbnb case study, including BPMN, UML diagrams, API documentation, and the final report.

## What has been done

### 1. BPMN of Airbnb
- Added the business process model for the Airbnb platform workflow.
- Covers key interactions among the platform, host, guest, and payment service.

### 2. Use Case and Class Diagram of Airbnb
- Added the use case model showing major actors and system functionalities.
- Added the class diagram showing the main entities, relationships, and responsibilities of the Airbnb system.

### 3. Collaboration Diagram of Airbnb
- Added the collaboration diagram to show how objects interact during the Airbnb workflow.

### 4. Sequence and State Diagram of Airbnb
- Added the sequence diagram to illustrate the order of interactions between system components.
- Added the state diagram to represent the lifecycle of important system states such as booking and status changes.

### API Documentation
- Added API documentation for the Airbnb system design.

### Final Report
- Added the final Airbnb report summarizing the overall system design work.
